## Before you start

Keep each downloaded `.xlsx` as a clean original. For each chapter, open it and save a copy as an **Excel Macro-Enabled Workbook (\*.xlsm)** before adding code.

Check figures: Part I `Sales` total ₹177,518.00 (total quantity 89). Part II `Sales` total ₹363,804.00, monthly CTC ₹761,500, 8 unpaid invoices worth ₹277,990. Part III `Orders` total ₹658,324.00 from 255 units. Part IV `Sales` total ₹1,466,792 from 120 lines (keep the Part_IV folder together and save chapter workbooks inside it). Part V `Sales` total ₹56,436,966 from 5,000 lines; ₹54,469,741 from 4,807 lines excluding cancelled (keep the Part_V folder together; several chapters need Excel for Windows). Part VI: October 2026 sales ₹5,690,871 from 488 orders; receivables ₹2,735,330 outstanding at 31-Oct-2026, of which ₹1,287,430 overdue; branch returns 64 rows, ₹758,670 (keep the Part_VI folder together and save PartVI_Projects.xlsm inside it). Part VII: same October figures as Part VI; the four capstone files hold 410 orders, of which 388 are clean, worth ₹3,835,080 (keep the Part_VII folder together and save PartVII_Work.xlsm inside it; never edit the capstone CSV files in Excel). Examples from Part II onwards use a fixed report date of 31-Oct-2026.
