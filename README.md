## Before you start

Keep each downloaded `.xlsx` as a clean original. For each chapter, open it and save a copy as an **Excel Macro-Enabled Workbook (\*.xlsm)** before adding code.

Check figures: Part I `Sales` total ₹177,518.00 (total quantity 89). Part II `Sales` total ₹363,804.00, monthly CTC ₹761,500, 8 unpaid invoices worth ₹277,990. Part III `Orders` total ₹658,324.00 from 255 units. Part IV `Sales` total ₹1,466,792 from 120 lines (keep the Part_IV folder together and save chapter workbooks inside it). Examples from Part II onwards use a fixed report date of 31-Oct-2026.
